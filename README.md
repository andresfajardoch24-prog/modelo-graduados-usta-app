# Modelo de Transformación de los Graduados · USTA (visualización)

Documento técnico de la Fase 1 del *Modelo Institucional de Seguimiento y Evaluación de la
Transformación de los Graduados* de la Universidad Santo Tomás, en Streamlit.

Consultoría Estadística 2026-II · Dylan Fajardo, Valentina Huertas y Manuel Molina.

## ▶ [Abrir el documento técnico en línea](https://modelo-graduados-usta-app-vvqu6ohutb6r2tbms6ns4s.streamlit.app)

Se abre en el navegador, sin instalar nada. Si la app estuvo varios días sin uso, Streamlit muestra
el botón *«Yes, get this app back up!»*: haga clic y espere unos segundos.

Este repositorio contiene **solo la aplicación y cifras agregadas** (porcentajes, intervalos e
índice). No contiene bases de datos ni información que identifique a una persona. El código
completo y las bases (cifradas) están en un repositorio privado del equipo.

## Ejecutar en local

```bash
pip install -r requirements.txt
python -m streamlit run streamlit_app/app.py
```
